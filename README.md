# Palenight Exact

Material Theme Palenight with the exact colors that [Shiki](https://shiki.style) uses to highlight code. Your editor will match code snippets on blogs and docs sites that render with Shiki's `material-theme-palenight`.

## Palette

| Token | Color |
|---|---|
| Background | `#292D3E` |
| Text | `#BABED8` |
| Keywords | `#C792EA` |
| Types and classes | `#FFCB6B` |
| Punctuation and operators | `#89DDFF` |
| Variables and properties | `#F07178` |
| Strings | `#C3E88D` |
| Numbers | `#F78C6C` |
| Functions | `#82AAFF` |
| Comments | `#676E95` |
| Booleans | `#FF9CAC` |

## Tip

Shiki colors code with TextMate grammars only. For the closest match, turn off semantic highlighting:

```json
"editor.semanticHighlighting.enabled": false
```
